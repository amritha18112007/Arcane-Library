THE PROJECT

Arcane Library is a fantasy-inspired digital library designed to make browsing books feel more immersive than a traditional webpage.

The project combines CSS animations, interactive navigation, book previews, and an atmospheric library design.

STRUGGLES & SOLUTIONS

INTERACTIVE DESIGN

One of the biggest challenges I faced was creating interactive features. I understood how CSS selectors such as :target, :checked, Sibling selectors, pseudo-elements, transitions, transforms, and 3D properties could be combined to create interactions.

CONSISTENCY

Another challenge was keeping the design consistent while adding multiple pages and features. I solved this by organizing the styling with CSS variables, reusable classes, and a consistent colour palette instead of styling every element separately.
